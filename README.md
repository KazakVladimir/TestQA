# TestQA
В данном репозитории представлены результаты выполнения домашних заданий в рамках курса "Сценарное тестирование в 1С: настройка и практика использования".
Ключевые темы: Vanessa Automation, Turbo Gherkin, причины падения тестов, настройки автоинструкций, создание тестовых данных, а также тесты форм, ТЧ, движений документов, отчетов.
